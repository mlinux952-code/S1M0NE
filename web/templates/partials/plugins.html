Ajouter un plugin

Fichier local : dépose un .py dans le dossier ci-dessus, avec une fonction décorée @hookimpl (s1mone_connectors et/ou s1mone_task_handlers) — voir plugins_local/README.md et plugins_local/examples/ pour des modèles.

Paquet pip : ajoute un entry point du groupe s1mone dans ton pyproject.toml — voir examples/s1mone-plugin-example/ pour un exemple complet et installable (pip install -e examples/s1mone-plugin-example).
